ハルモン プライバシーポリシー

施行日：2026年11月6日

90ms（以下「開発者」）は、Android・iOSアプリハルモン（以下「本アプリ」）をご利用の方の個人情報を大切に扱います。本ポリシーでは、本アプリが扱う情報の保存場所と利用方法を説明します。

1. 開発者が収集する情報

本アプリには会員登録・ログインがありません。記録、大切な日、メモ、一日のふりかえりに書いた内容や、自分で付けた名前は利用者の端末内に保存され、開発者に送信されることはありません。開発者がこれらの内容を閲覧・保管・提供することはありません。ペット・庭の情報や設定も端末に保存されますが、下記の利用統計には、選んだ機能・設定の種類やオン・オフなど、あらかじめ定めた値が含まれることがあります。

ただし本アプリが異常終了した場合は、原因を調べて修正するため、次のエラーレポートがGoogleのFirebase Crashlyticsを通じて開発者に届きます。入力した記録やメモなどの内容は含まれません。

  • エラーが起きたコードの位置（スタックトレース）とそのときのアプリの状態（アプリのバージョン、メモリ、画面の向きなど）
  • 端末の情報（機種、OSバージョンなど）
  • Crashlyticsのインストール識別子（エラーが起きたインストール数を数えるために使い、利用者や端末を特定しません）

アプリの利用統計（バージョン1.1.3から）：どの画面や機能が使われているかを把握してアプリを改善するため、Google Analytics for Firebase（GA4）を利用します。利用統計がオンの場合、次の情報がGoogleに送信され、開発者が統計として確認します。

  • アプリの利用記録：アプリの起動・画面の表示・機能の利用・広告の表示などのイベント、機能の種類・結果、設定のオン・オフ、件数や時間の範囲など、アプリが定めた値
  • アプリと端末の情報：アプリのバージョン、端末の機種、OSバージョン、言語など。Googleは接続元のIPアドレスを国・地域などのおおよその位置の推定やサービスの運営に利用し、元のIPアドレスは利用後に破棄します。本アプリはGPSなどの正確な位置情報を収集しません。
  • アプリインスタンスID：インストールごとにGoogleが生成するランダムな識別子で、インストール数や利用統計の計算に使います。開発者は氏名・メールアドレスやログインアカウントと関連付けません。

利用統計には、記録・メモ・ふりかえりに書いた文章、自分で付けた名前、外部カレンダーの予定の内容、検索語、ふりかえりの気持ち、正確な予定の日付・時刻、記録IDを送りません。この統計での広告ID（Androidの広告ID・IDFA）とIDFVの収集はオフにしており、統計をパーソナライズ広告に利用しません。第2項の広告SDKによる情報の処理とは別です。

利用統計は初期設定でオンですが、マイ記録 › 設定 › 利用統計 › 利用統計を送るからいつでもオフにできます。選択を反映した後は、新たな利用統計の収集・送信を停止します。すでに収集した情報が直ちに削除されるわけではありません（保管期間は第5項）。同意が必要な地域では、関連する同意が得られた場合のみ送信します。この選択は端末ごとに保存され、オフにしても他の機能をそのまま使えます。

また、利用者がマイ記録 › 設定 › ご意見を送るから自分でご意見を送ったときに限り、お問い合わせに答え、アプリの問題を確認・改善するため、次の情報が開発者に届きます。ご意見を送らなければ、この機能を通じた情報は送信されません。

  • ご意見の内容（利用者が書いた文章）
  • 返信用メールアドレス（任意。入力して同意した場合のみ）
  • アプリと端末の情報（アプリのバージョン・ビルド、OSバージョン、端末のモデル、アプリの言語）。広告IDやインストールIDなどの識別子は送りません。

ご意見はハルモンのウェブサイト（harumung.app）の中継サーバー（Cloudflare）を通じて、開発者のSlackワークスペースとGitHub非公開リポジトリのイシューに届きます。メールアドレスはSlackにのみ届き、GitHubのイシューには入れません。中継サーバーはご意見を保存しません。送信が多すぎるのを防ぐためCloudflareが接続元のIPアドレスを処理しますが、開発者はIPアドレスを受け取ったり保管したりしません。

2. 広告と外部サービス（Google AdMob）

本アプリは無料で提供するため、Google AdMobの広告を表示します。広告の配信と測定のため、Googleが次の情報を収集・処理する場合があります。

  • 広告ID（Androidの広告ID、iOSの広告識別子IDFA）・アプリセットID・iOSのベンダー識別子（IDFV）などの端末識別子、端末とアプリの情報（機種、OSバージョン、言語など）
  • IPアドレスと、そこから推定されるおおよその位置
  • 広告の表示・タップなど広告とのやり取り
  • アプリの起動時間・フリーズ率など、アプリと広告SDKのパフォーマンスに関する診断情報

欧州経済領域（EEA）・英国・スイスおよび米国の一部の州の利用者には、広告をリクエストする前にGoogleの同意ツール（User Messaging Platform）で選択していただきます。選択は本アプリのマイ記録 › 設定 › 広告のプライバシー設定からいつでも変更できます。Androidでは端末の設定で広告IDをリセット・削除することもできます。

iOSでは、広告識別子（IDFA）を使う前にAppleのApp Tracking Transparency（ATT）の画面で許可を確認します。許可した場合にのみIDFAがGoogleに渡され、他社のアプリやウェブサイトから得た情報と組み合わせて、パーソナライズ広告や広告の測定に使われることがあります（App Storeでは「ユーザのトラッキングに使用されるデータ」と表示されます）。許可しなくても本アプリのすべての機能をそのまま使え、選択はiPhone・iPadの設定 › プライバシーとセキュリティ › トラッキングからいつでも変更できます。

詳しくはGoogleプライバシーポリシーとGoogleのサービスを使用するサイトやアプリから収集した情報のGoogleによる使用をご覧ください。

3. 端末の権限と利用目的

  • カレンダー（任意、iOSはカレンダーへのフルアクセス）：外部カレンダー連携をオンにすると、端末のカレンダーの予定を本アプリに表示し、選んだ記録を指定したカレンダーに保存します。処理は端末内で行われ、開発者には送信されません。そのカレンダーがGoogleカレンダーなどのアカウントと同期している場合、同期にはそのサービスのポリシーが適用されます。Androidでは外部カレンダー連携で「今すぐ同期」を押すか自動同期をオンにすると、端末にそのカレンダーアカウントの同期を依頼します。iOSでは端末に追加したiCloud・Googleなどのカレンダーを同じように端末内で読み書きし、アカウントの同期はiOSが行います。
  • 通知（Androidは正確なアラーム・再起動後の実行を含む）：設定した記録の通知、一日のふりかえり・チェックインの通知、朝のまとめと夜のプレビューを時間どおりに届け、端末の再起動後も予約を保つために使います。通知は端末内で予約され、サーバーを経由しません。
  • 全画面通知（Android、任意）：ペット通知画面をオンにした場合にのみ使います。
  • インターネット・ネットワーク状態：広告の読み込み、広告の同意状態の確認、第1項のエラーレポート・オンにした利用統計と利用者が送るご意見の送信に使います。
  • アプリのロック（任意）：端末の画面ロック・生体認証機能（iOSはFace ID・Touch ID・パスコード）を使います。本アプリは認証に成功したかどうかだけを受け取り、指紋や顔などの生体情報にアクセスしたり保存したりすることはありません。
  • 写真の追加（iOS、任意）：記念カードを写真に保存するときにのみ使います。本アプリが写真を読み取ることはありません。
  • トラッキングの許可（iOS、任意）：第2項の広告識別子（IDFA）を使うために確認します。
  • Siriとショートカット（iOS）：「ハルモンに記録を追加」で話した内容はAppleが文字に変換して本アプリに渡し（Appleのプライバシーポリシーが適用されます）、本アプリはその文字を端末内に記録として保存します。
  • 共有拡張とウィジェット（iOS）：ほかのアプリからハルモンに共有したテキスト・リンクと、ウィジェットに表示する今日の予定の要約は、端末内の本アプリ専用の保存領域（App Group）に置き、本アプリとウィジェットが読み取ります。開発者には送信されません。

4. バックアップ

  • ファイルのバックアップ：利用者が書き出したバックアップファイルは利用者が選んだ場所に保存され、その管理は利用者が行います。
  • Androidのバックアップ：端末でGoogleバックアップがオンの場合、本アプリのデータは利用者のGoogleアカウントのバックアップに含まれ、Googleのポリシーに従って保管されます。開発者はこのバックアップにアクセスできません。
  • iOSのバックアップ：iCloudバックアップまたはコンピュータ（Finder・iTunes）へのバックアップがオンの場合、本アプリのデータはそのバックアップに含まれ、Appleのポリシーに従って、または利用者のコンピュータに保管されます。開発者はこのバックアップにアクセスできません。
  • 写真の保存と共有：記念カードを保存すると端末の写真アルバムに保存され、記念カードやメモを共有すると利用者が選んだアプリにのみ送られます。開発者には送信されません。

5. 保管と削除

端末に保存した記録などは、アプリ内で削除するか本アプリをアンインストールすると端末から削除されます。開発者は入力した記録の内容を保管しません。第1項の「ご意見を送る」で受け取ったメールアドレスは返信を終えたら削除し、遅くとも受け取った日から3か月以内に削除します。ご意見の内容とアプリ・端末の情報は、アプリの修正・改善の記録として本アプリを提供する間保管し、削除のご依頼があれば遅滞なく削除します。第1項のエラーレポートはFirebaseに90日間保管された後に削除されます。広告に関してGoogleが処理した情報の保管はGoogleのポリシーに従います。

第1項の利用統計のユーザー単位・イベント単位データの保管期間は14か月に設定し、期間を過ぎたデータはGoogleの月次の削除処理で削除されます。新たな利用により、ユーザー識別子の保管期間が再び始まる場合があります。この保管設定は集計済みの標準統計レポートには適用されないため、集計統計はさらに長く残る場合があります。詳しくはGoogle アナリティクスのデータ保持の説明をご覧ください。

6. 第三者提供と処理委託

開発者は利用者の個人情報を第三者に提供しません。第1項のエラーレポートはGoogle LLCのFirebase Crashlyticsに処理を委託しており、エラーが起きたときにネットワーク経由で米国などの国外にあるGoogleのサーバーへ送信され、90日間保管されます。また第2項の広告配信のため、本アプリに含まれる広告SDKを通じてGoogleが情報を直接収集・処理し、国外（Googleのサーバー）に送信される場合があります。Google Playの「データセーフティ」では、広告SDKがGoogleに送るこの情報は「共有」と表示され、App Storeの「Appのプライバシー」では収集するデータ（デバイスIDはトラッキングに使用）として表示されます。

第1項の利用統計はGoogle LLCのGoogle Analytics for Firebaseに処理を委託します。アプリの利用に伴い、アプリの利用記録・アプリと端末の情報・アプリインスタンスIDがネットワーク経由で米国などの国外にあるGoogleのサーバーへ送信され、利用状況の分析とサービスの改善に使われます。保管は第5項のとおりで、第1項の利用統計の設定から送信を停止できます。Googleによる情報の取り扱いはGoogleプライバシーポリシーとGoogle アナリティクスのデータ保護の説明をご覧ください。

第1項の「ご意見を送る」は次の事業者に処理を委託しており、ご意見を送ったときにネットワーク経由で国外（米国）に送信されます。「ご意見を送る」を使わなければ送信されず、使わなくても他の機能の利用に不利益はありません。

  • Cloudflare, Inc.（米国、プライバシーポリシー）：ご意見の中継サーバーの運営。ご意見の内容・メールアドレス・アプリと端末の情報・IPアドレスを中継する間だけ処理し、保存しません。
  • Slack Technologies, LLC（米国、プライバシーポリシー）：開発者がご意見を受け取って読むワークスペース。ご意見の内容・メールアドレス（入力した場合）・アプリと端末の情報を第5項の期間保管します。
  • GitHub, Inc.（米国、プライバシーポリシー）：アプリの改善を管理する非公開リポジトリのイシュー。ご意見の内容・アプリと端末の情報（メールアドレスを除く）を第5項の期間保管します。

10. 紹介サイト

ハルモンの紹介サイト（harumung.app）では、訪問数と流入元を知るために Cloudflare Web Analytics を使用しています。Cookie は使用せず、個人を特定する情報は収集しません。Cloudflare が集計するのは、ページのアドレス、参照元ページ、国、ブラウザと端末の種類などの訪問統計だけです。サイトには広告・会員登録・情報を送信するフォームはなく、体験（やることのチェック、日数の計算）はお使いのブラウザの中だけで動作します。アプリ内の記録はこの統計に含まれません。Cloudflare による情報の取り扱いは Cloudflare のプライバシーポリシーに従います。
